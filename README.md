# [GICAT](https://github.com/css-lab-rwth/gicat)
GICAT (General Isomorphic Code Analysis Tool) visualizes the class structure of an object-oriented programmed software project. It shows the genealogy based on Git, as well as the software project’s heredity of classes. Developed at the [css-lab](https://github.com/css-lab-rwth) at RWTH Aachen University.

### 🛠️ Tech-Stack
JavaScript, Vue.js, Node.js, Electron, Pinia, Vuetify, D3.js
